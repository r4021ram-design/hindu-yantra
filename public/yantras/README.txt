SVG Guidelines:
---------------
• Format: Standard SVG (XML-based vector)
• Aspect Ratio: 1:1 (Square, e.g. viewBox="0 0 1000 1000")
• Quality: Infinite vector resolution (never pixelates)
• Layers (Optional but recommended): Group layers with IDs or classes:
    - Bhupura (Outer gates / भूपुर)
    - Shodasha-Dala (16 Petals / १६-दल कमल)
    - Ashta-Dala (8 Petals / ८-दल कमल)
    - Trikona (Sacred Intersecting Triangles / त्रिकोण)
    - Bindu (Central Cosmic Point / बिन्दु)
