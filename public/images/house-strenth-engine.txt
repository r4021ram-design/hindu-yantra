🔹 (A) UCHCHA BALA (Exaltation Strength)

Formula:

Uchcha Bala = (Distance from Debilitation Point / 180°) × 20

If planet exactly exalted → 20
If exactly debilitated → 0

function uchchaBala(longitude: number, exaltationDegree: number): number {
  const distance = Math.abs(longitude - exaltationDegree)
  return (1 - (distance / 180)) * 20
}
