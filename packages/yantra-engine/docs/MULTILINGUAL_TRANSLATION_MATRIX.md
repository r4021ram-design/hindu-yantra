## 1. Supported Languages Matrix

Every Yantra entry MUST provide titles and canonical names in 5 languages:

| Code | Language | Script / Standard | Example (`sri_yantra`) |
| :--- | :--- | :--- | :--- |
| `sa` | Sanskrit | Devanagari Script | श्रीचक्र यन्त्रम् |
| `iast` | IAST | Transliteration Standard | Śrī Cakra Yantram |
| `hi` | Hindi | Devanagari Script | श्री यन्त्र |
| `en` | English | Romanized Academic Title | Shri Yantra (Sacred Cosmic Geometry) |
| `gu` | Gujarati | Gujarati Script | શ્રી યંત્ર |
