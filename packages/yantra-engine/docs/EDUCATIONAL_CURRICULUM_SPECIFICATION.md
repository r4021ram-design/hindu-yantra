# SGOS Educational Curriculum & Quiz Specification

**Package Scope**: `@yantra/engine` / Hindu Panchang Application  
**Specification Version**: 1.0.0-sgos.educational-curriculum  

---

## 1. Objectives & Pedagogy

The **Educational Curriculum Subsystem** provides a guided, interactive learning path for students, researchers, and practitioners exploring sacred geometry.

---

## 2. Core Modules

1. **Guided Lessons**: Layer-by-layer progressive lessons (Bindu, Trikona, 9 Navavaranas, Lotus Petals, Bhupura).
2. **Terminology Glossary**: Complete index of Tantric geometry terms (Bindu, Trikona, Avarana, Marma, Sandhi).
3. **Symbolism Guide**: Philosophical mapping of geometry to Tattvas and consciousness.
4. **Interactive Quizzes**: Multiple-choice assessment with instant explanation feedback.
5. **Progress Tracking**: Browser `localStorage` persistence (`sgos_learning_progress`).
