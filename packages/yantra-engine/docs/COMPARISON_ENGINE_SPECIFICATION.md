# SGOS Comparison Engine Specification

**Package Scope**: `@yantra/engine`  
**Specification Version**: 1.0.0-sgos.comparison-engine  

---

## 1. Overview & Comparative Rules

The **Comparison Engine** compares two geometry models, traditions, or dimensional representations side-by-side.

### Strict Governance Rule:
- **Highlight Only Documented Differences**: The comparison diff matrix MUST display documented structural and textual differences only. It does not synthesize non-scriptural assumptions.

---

## 2. Comparison Categories

1. **Yantra vs Yantra**: Compare structural parameters between two distinct Yantras (e.g., Shri Yantra vs. Kuber Yantra).
2. **Tradition vs Tradition**: Compare lineage variations (e.g., Srividya Sampradaya vs. Kaula Tradition).
3. **2D Planar vs 3D Meru**: Compare 2D vector flat relief against 3D Maha Meru pyramid elevation.

---

## 3. Comparative Attributes Evaluated

- Primary Deity & Element Tattva
- Symmetry Group ($D_4, C_4$)
- Solved Triangles Count
- Graph Topology Node Count
- Active Avarana Layers
- Scriptural Citation References
