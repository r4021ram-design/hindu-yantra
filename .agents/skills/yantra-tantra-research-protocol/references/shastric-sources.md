# शास्त्रीय संदर्भ ग्रन्थ निर्देशिका
## Canonical Shastric Sources Master Directory

जब भी किसी नए यन्त्र, तन्त्र अथवा पूजा विधान का अनुसन्धान करना हो, तो निम्नलिखित तालिका के अनुसार सम्बन्धित मूल ग्रन्थ के पटल को सीधे परामर्श करें:
